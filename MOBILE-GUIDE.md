# 📱 Guide Mobile - Alertes en 3 Étapes

## 🚀 SUPER SIMPLE - 3 ÉTAPES

### Étape 1 : Active GitHub Actions

1. Ouvre ton navigateur mobile
2. Va sur : https://github.com/samydev94-max/Newletter
3. Va dans **Settings** (roue crantée)
4. Clique **Actions** → **General**
5. Scroll tout en bas
6. Sélectionne **"Read and write permissions"**
7. Clique **Save**
8. Retourne en arrière et clique l'onglet **Actions** (en haut)
9. Si tu vois un bouton vert "I understand...", clique dessus

### Étape 2 : Télécharge NTFY

**Android :**
https://play.google.com/store/apps/details?id=io.heckel.ntfy

**iOS :**
https://apps.apple.com/app/ntfy/id1625396347

### Étape 3 : Abonne-toi

**Option A - Le plus simple :**
1. Ouvre ce lien dans ton navigateur mobile :
   ```
   https://samydev94-max.github.io/Newletter/alerts.html
   ```
2. Clique le gros bouton violet "S'ABONNER AUX ALERTES"
3. L'app NTFY s'ouvre automatiquement
4. Confirme l'abonnement

**Option B - Manuellement dans NTFY :**
1. Ouvre l'app NTFY
2. Appuie sur le bouton "+" (en bas à droite)
3. Entre ce nom exactement : `crypto-news-samy-2024`
4. Appuie "Subscribe"

## ❓ Questions

**Q : C'est vraiment gratuit ?**
R : Oui ! GitHub Actions est gratuit pour les repos publics. NTFY aussi.

**Q : Faut-il que mon téléphone soit allumé ?**
R : Non ! GitHub Actions tourne dans le cloud. Tu reçois juste les notifications.

**Q : Puis-je changer l'heure ?**
R : Oui, mais ça nécessite de modifier le fichier `.github/workflows/crypto-news-alerts.yml`

**Q : Je peux partager avec des amis ?**
R : Oui ! Donne-leur juste le lien `alerts.html` et ils pourront s'abonner aussi au même topic.

**Q : Comment changer le topic (pour un topic privé) ?**
R : Modifie ces 2 fichiers :
- `.github/workflows/crypto-news-alerts.yml` : ligne avec `ntfy.sh/crypto-news-samy-2024`
- `alerts.html` : ligne avec `crypto-news-samy-2024`
